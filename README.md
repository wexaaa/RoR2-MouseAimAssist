# Mouse Aim Assist для Risk of Rain 2

Клиентский мод для Steam-версии игры. Режим «Все враги на карте» размножает каждую стандартную пулю или выпущенный снаряд по всем живым противникам. Камера при этом остаётся неподвижной. Также доступны сайлент-аим на одну цель и прежний режим мягкого доведения.

## Управление

По умолчанию сайлент-аим работает постоянно и переключается клавишей **F6**. Все параметры доступны в игре:

`Настройки → Mod Options → Mouse Aim Assist`

- **Сайлент-аим** — мгновенное наведение направления атаки без движения камеры.
- **Все враги на карте** — направляет один выстрел сразу во всех живых противников, игнорируя дальность и стены.
- **Переключатель** — клавиша включения и выключения во время игры; по умолчанию F6.
- **Клавиша активации** — необязательная клавиша удержания; `None` означает постоянную работу.
- **Сила срабатывания** — 0–100% для режима мягкого доведения.
- **Плавность** — скорость, с которой выполняется доведение.
- **Радиус захвата** — угол поиска цели вокруг центра экрана.
- **Дальность** — максимальная дистанция до цели.
- **Только видимые цели** — игнорировать противников за стенами.
- **Смещение точки прицеливания** — поднять или опустить точку наведения.
- **Двигать камеру** — визуально поворачивать камеру; при отключении корректируется только направление атаки.
- **Показывать индикатор** — выводит ON/OFF/LOCK в правом верхнем углу.

Рекомендуемые мягкие настройки: сила 25–40%, плавность 7–12, радиус 10–16°.

## Установка через r2modman

1. Установите **r2modman** и создайте профиль Risk of Rain 2 для Steam.
2. Установите в профиль `RiskOfThunder-BepInExPack` и `Rune580-Risk_Of_Options`.
3. В r2modman откройте `Settings → Import local mod` и выберите ZIP-файл мода.
4. Запускайте игру кнопкой `Start modded`.

Настройки также сохраняются в `BepInEx/config/local.wexaa.mouseaimassist.cfg`.

Используйте мод в одиночной игре или в приватном лобби с согласия остальных игроков.
